# Operator URL Intent Boundary

Merged into `issues/operator-priority-crawl-request.md` on 2026-09-10.

Supplying a URL does not by itself establish that it should receive priority.
The current ledger has no operator-provenance field, and the operator CLI
requests ordinary queue insertion. Requirements for urgency and audit history
should be decided together in the remaining issue rather than through two
separate conceptual tasks.
